# User Activity Dashboard

Simple frontend project that displays users from [DummyJSON](https://dummyjson.com) and loads each user's todos on demand. 

## Prerequisites

- Git
- A modern browser (Chrome, Edge, Firefox, Safari)


## Clone the project

```bash
git clone https://github.com/abhinav-singhania/user-activity-dashboard.git
cd user-activity-dashboard
```

## Run the Project

Open `index.html` in your browser.


## Project Structure
- `index.html` - App entry point
- `src/styles.css` - Styling for dashboard
- `src/main.js` - Data rendering, accordian behavior and service layer
